# plan/ — historical design plans and notes

The `*.md` files in this directory are design plans, architecture notes and
procedures written during the 2026 development cycle (arm teach-and-replay,
the ft_servo C++ extension, motor velocity safety, the locomotion +
manipulation integration, the real-data comparison SOP, ...). They are kept for
the rationale they record — why a piece was built the way it was — not as a
description of the tree today.

Some of them describe layouts or file names as they stood at the time (for
example `st_servo/`, a standalone `motor_bindings` package, `control/motor/`)
and are not maintained as current documentation. For the current map of the
code, the processes and the ports, see [`../docs/ARCHITECTURE_MAP.md`](../docs/ARCHITECTURE_MAP.md);
for how to build and run it, [`../docs/SETUP.md`](../docs/SETUP.md) and
[`../docs/OPERATIONS.md`](../docs/OPERATIONS.md).
