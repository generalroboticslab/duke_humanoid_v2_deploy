# Third-party notice — SYD Dynamics EasyProfile SDK

The sources in this directory other than `CMakeLists.txt` are the EasyProfile
SDK from SYD Dynamics ApS — the host-side protocol library for the TransducerM
TM171 IMU — redistributed here under the BSD-2-Clause terms carried in each
header file (Copyright (c) 2017 SYD Dynamics ApS; the three `.cpp` files carry
the copyright line and refer to their header).

Upstream: SYD Dynamics EasyProfile, version 1.1.9 (R), Jul 27 2016, as the
`EasyProfile.h` header states. The companion files carry their own component
versions with the same release date — `BasicTypes.h` V1.1.6 (R),
`EasyObjectDictionary.h` 1.1.8 (R), `EasyProtocol.h` v2.1 (R), `EasyQueue.h`
V1.0 (R). The headers say the files are generated by the vendor's IMU
Assistant tool and ship with the device; they name no repository URL, so there
is no upstream commit to pin.

Files (8):

```
BasicTypes.h
EasyObjectDictionary.cpp   EasyObjectDictionary.h
EasyProfile.cpp            EasyProfile.h
EasyProtocol.cpp           EasyProtocol.h
EasyQueue.h
```

`CMakeLists.txt` is ours: it builds the eight files as the `EasyProfile`
library that `../imu_nanobind.cpp` / `../imu.hpp` — our nanobind binding, in
the parent directory — link into the `imu_nanobind` extension.

## Local modifications to the upstream sources

None known. The files are recorded here as received: they carry no edit
markers, and the vendor's header banners and line endings are intact (six
files CRLF, `EasyProtocol.h` and `EasyQueue.h` LF, as received). There is no
vendor checkout to diff against, so "unmodified" means "not touched by this
project", not "verified against an upstream commit". Keep them byte-exact; do
not normalise line endings.
